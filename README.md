## 1. Project Overview

The project titled **"Factors Affecting Student Performance"** focuses on analysing students' academic performance in Mathematics, Reading, and Writing.

The main purpose is to understand how different factors, such as gender, race/ethnicity, parental level of education, lunch type, and test preparation courses, are associated with students' examination scores.

This project uses Python and data analysis techniques to explore the dataset and identify meaningful patterns.

## 2. Objectives

- To understand and analyse students' academic performance.
- To examine Mathematics, Reading, and Writing scores.
- To study the relationship between different factors and student performance.
- To compare the performance of students who completed test preparation courses with those who did not.
- To represent findings using charts and graphs.

## 3. Dataset Description

**Dataset Name:** Students Performance in Exams  
**Source:** Kaggle  
**File Name:** StudentsPerformance.csv

The dataset contains:
- 1,000 student records.
- 8 columns.
- 5 categorical variables.
- 3 numerical variables.

### Variables Used

**Categorical Variables:**
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course

**Numerical Variables:**
- Math Score
- Reading Score
- Writing Score

## 5. Project Methodology – Five Phases

1. **Problem Understanding and Data Collection:** Understanding the project topic and collecting the student performance dataset from Kaggle.

2. **Data Cleaning and Wrangling:** Checking missing values, duplicate records, data types, and categorical values.

3. **Exploratory Data Analysis (EDA):** Calculating averages, analysing scores, comparing categories, and examining relationships between subjects.

4. **Visualisation and Analytical Evaluation:** Creating graphs and charts to understand score distributions and compare student groups.

5. **Observations and Reporting:** Interpreting the results, identifying patterns, and preparing the final project report.

## 6. Key Findings

- The average Mathematics score was approximately 66.09.
- The average Reading score was approximately 69.17.
- Reading had the highest average score among the three subjects.
- Students who completed the test preparation course generally achieved higher average scores in all three subjects.
- Reading and Writing scores showed a strong positive correlation of approximately 0.955.
- The dataset contained no missing values or duplicate records.

## 7. Limitations

- The analysis uses a dataset of only 1,000 student records.
- The dataset contains limited information about students.
- Factors such as study hours, attendance, and teaching quality are not included.
- The analysis identifies relationships but does not prove cause and effect.
- The project focuses on descriptive analysis and does not include a machine learning prediction model.

## 8. Conclusion

This project helped in understanding how different factors are associated with students' academic performance.

Using Python libraries and Exploratory Data Analysis, the project identified patterns in Mathematics, Reading, and Writing scores.

The findings suggest that test preparation and relationships between subject scores are useful areas to explore when studying academic performance.
